# WorkReport HR-Pro - 工作汇报系统

基于 AI Agent 的智能工作汇报与聚合系统，解决传统周报催办低效、格式不统一、信息碎片化、总结汇总耗时等痛点。

## 仓库目录

```
├── 00-产品框架与原型/    产品设计文档、架构图、原型
├── 01-v1.0开发/          v1.0 版本开发（含每日工作记录）
├── 02-v2.0开发/          v2.0 版本迭代开发
├── 03-skill工具/         专属 Agent Skill 工具集
└── README.md             本文件
```

## 版本规划

| 版本 | 范围 | 状态 |
|------|------|------|
| v1.0 | 核心功能 MVP：工作事项管理、周报填写与提交、年度目标锚定、AI审阅Agent、催办Agent、企业微信集成 | 待开发 |
| v2.0 | 增强功能：报告Agent、解读Agent、待办Agent、月报/季报/年报自动生成、HTML/PDF输出 | 待规划 |
| v3.0 | 扩展功能：PPT生成、与看板工具等大中台模块对接、更多集成 | 待规划 |
