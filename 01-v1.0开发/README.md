# v1.0 开发

核心功能 MVP 版本。

## 目录结构

```
├── README.md          本文件
├── src/               源代码
│   ├── frontend/      前端代码
│   └── backend/       后端代码
└── YYYY-MM-DD/        每日工作记录（开发日志）
```

## 开发日志规范

每次开发完成后，在当天日期目录下保存：
- 工作成果文件
- 简要的开发日志（做了什么、遇到的问题、决策记录）

示例：`2026-08-12/notes.md`
